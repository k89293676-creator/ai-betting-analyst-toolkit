# One‑Shot Profit‑Launch Prompt for Replit

Copy and paste the entire block below into the **Replit shell** (or give it to the Replit AI Assistant). It will deploy your AI Betting Analyst Toolkit with Telegram, Gemini, and an autonomous training loop for continuous improvement. 

**⚠️ Before starting**:  
- Have these secrets ready: `DATABASE_URL` (Neon/Supabase), `TELEGRAM_BOTTOKEN`, `TELEGRAM_CHATID`, `ODDS_API`, `GEMINI_API_KEY`.  
- Profit is **never guaranteed** – this toolkit maximises your edge, but you must use disciplined bankroll management (quarter Kelly) and never bet more than you can lose.

## 🚀 One‑Shot Setup & Training Pipeline

```bash
#!/bin/bash
# 1. Clone & enter repo
git clone https://github.com/k89293676-creator/ai-betting-analyst-toolkit.git
cd ai-betting-analyst-toolkit

# 2. Install pnpm if missing
npm install -g pnpm

# 3. Install dependencies
pnpm install

# 4. Set up environment secrets (paste your values)
cat > .env <<EOF
DATABASE_URL=postgresql://...
TELEGRAM_BOTTOKEN=your_bot_token
TELEGRAM_CHATID=your_chat_id
ODDS_API=your_odds_api_key
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash
USE_AI_PREDICTIONS=true
MIN_CONFIDENCE_THRESHOLD=0.70
MAX_AI_BET_PERCENT=0.05
EOF

# 5. Run database migrations
pnpm --filter @workspace/db run push

# 6. Add autonomous training tables & scripts (one‑liner)
pnpm add @google/genai drizzle-orm pg drizzle-zod -w
mkdir -p lib/gemini/src artifacts/training-worker/src

# 7. Download and inject training pipeline (using curl + heredoc)
curl -o scripts/training_pipeline.sh https://raw.githubusercontent.com/k89293676-creator/ai-betting-analyst-toolkit/main/scripts/training_pipeline.sh
chmod +x scripts/training_pipeline.sh
./scripts/training_pipeline.sh   # This adds vector embeddings, feedback loop, cron scheduler

# 8. Build everything
pnpm run build

# 9. Start API server with scheduler (keeps training alive)
pnpm --filter @workspace/api-server run dev &

# 10. Send test Telegram message to confirm integration
curl -X POST http://localhost:5000/api/telegram/test

# 11. Launch background training (updates every 6 hours)
nohup pnpm --filter @workspace/training-worker run start > training.log 2>&1 &

# 12. Display dashboard URL and health check
echo "✅ Deployment complete! Dashboard: https://$(replit domain)/api/dashboard"
echo "📊 AI training active. Monitor accuracy at /api/metrics/performance"
